## Projects

### Order Book Fill Simulator

A small C++ program that simulates a market buy order moving through multiple ask levels.

It calculates:

- fills at each price level
- total execution cost
- average execution price
- slippage per share
- total slippage

More advanced versions will eventually use vectors, loops, order matching, and dynamic order book data.
